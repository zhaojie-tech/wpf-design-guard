# DG0002 — Margin/Padding off the spacing ladder

| | |
|---|---|
| Default severity | **Error** |
| Determinism | Deterministic |
| Detection surface | generator (AdditionalFiles XAML pipeline) |
| Fix support | `designguard fix` (span-level) |
| First shipped | v0.1.0 |

## Message

```text
Component '{0}' of {1} '{2}' is not on the spacing ladder {3}.
```

## Value judgement (取值口径)

- Reports one finding per offending component, span on that component.
- Single-component literals belong to DG0003; comments are stripped before evaluation.
