# DG0013 — Parenthesis stacking / ellipsis abbreviation in button text

| | |
|---|---|
| Default severity | **Warning** |
| Determinism | Deterministic |
| Detection surface | generator (AdditionalFiles XAML pipeline) |
| Fix support | none (report only) |
| First shipped | v0.2.0 |

## Message

```text
Button text '{0}' uses {1}; rewrite the copy instead.
```

## Value judgement (取值口径)

- No automatic fix by design — rewriting user copy is not a mechanical operation.
