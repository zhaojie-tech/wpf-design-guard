# DG0014 — Implicit TextBlock style without base FontSize

| | |
|---|---|
| Default severity | **Error** |
| Determinism | Deterministic |
| Detection surface | CLI (whole-repo view) |
| Fix support | none (report only) |
| First shipped | v0.2.0 |

## Message

```text
Implicit TextBlock style at '{0}' does not set a base FontSize (falls back to the WPF 12px default).
```

## Value judgement (取值口径)

- CLI-only surface: implicit style chains resolve across App.xaml MergedDictionaries/pack URIs; multi-dictionary name clashes resolve by WPF load order (later wins).
