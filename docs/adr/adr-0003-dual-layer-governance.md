# ADR-0003: 硬零域 + 全局棘轮双层治理模型

状态：已采纳 ｜ 日期：2026-10-15

## 背景

单层全局棘轮放行一种漂移：违规从遗留文件挪进硬零域文件、总数不变即绿——生产闸的
真形态是双 assert（域内硬零 ∧ 全局 ≤ 基线），只留一层必漏（R1 评审 P0）。

## 决策

三层机制全部保留并工具化：

1. **豁免登记簿**：逐处登记（file + count + reason），双向相等——未登记违规红、
   stale 豁免（count 不匹配/文件已改）同样红；已豁免命中不进基线计数。
2. **硬零域**：域内规则命中即红，与全局计数无关；`baseline --update` 只动全局层。
3. **全局棘轮**：每规则未豁免计数 ≤ 基线；基线段缺失 = 全 0（严格门）——冷启动走
   `designguard init`，不存在「没配基线就静默放行」的状态。

封闭语义：全局计数不含硬零域命中；豁免指向硬零域 = 配置错误（exit 1）。

## 后果

- 「修完一个文件，违规挪到另一个文件」类漂移在结构上被硬零层拦截。
- CLI 在树红时拒绝 `baseline --update`（诚实重取基线 ≠ 消音器）。
