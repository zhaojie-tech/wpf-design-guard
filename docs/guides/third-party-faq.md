# 第三方库共存 FAQ

**Q：第三方 UI 库的控件不在 clickableTypes 清单里，命中区规则会误报吗？**
不会。不在清单/归属无法解析的类型一律计入「未检面」——不红、不豁免、报告可见。
`verify` 与 SARIF 输出都会列出未检面（如 v0.1 尚未实现的规则）。

**Q：第三方库的 XAML 会扫到吗？**
不会——扫描面是 MSBuild `@(Page)/@(ApplicationDefinition)` 投影（你的工程里被编译的
XAML），依赖库内部的 XAML 不在面内。`verify --project` 可以显式查看两面文件集差集。

**Q：第三方库样式里的 Setter 属性不存在（DG0012）算谁的问题？**
DG0012 对**你的** XAML 里的 Setter 负责。引用第三方样式定义文件不参与编译期求值
（不在投影面）。若你的代码继承第三方样式后写 Setter，符号解析沿基类链找属性；
找不到类型（如未引用对应程序集）计未检面，不误报。

**Q：工具会不会加载/执行我的程序集？**
不会。CLI 无代码执行（纯文本/模型/符号级）；生成器只读注入的文本与编译符号表。

**Q：与 XAML Styler 冲突吗？**
不冲突。XAML Styler 管格式（缩进/排序），WpfDesignGuard 管设计语义——正交。
