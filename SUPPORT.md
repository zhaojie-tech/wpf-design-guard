# Support

- **Bug / mis-fire**: open a [bug report](.github/ISSUE_TEMPLATE/bug_report.md) with a minimal reproduction.
- **Rule proposal**: [feature request](.github/ISSUE_TEMPLATE/feature_request.md) — real-incident evidence required.
- **Questions / adoption help**: GitHub Discussions (enabled once the repository is public).

See [SECURITY.md](SECURITY.md) for vulnerability reports (never file those as public issues).
